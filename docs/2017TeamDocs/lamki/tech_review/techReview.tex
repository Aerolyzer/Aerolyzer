\section{Horizon Detection}
	\subsection{Overview}
		Horizon detection in still images is a complex task due to infinite factors that affect image quality including camera perspectives, camera manufacturer, lighting, and many others.
		Aerolyzer's horizon detection classifier serves as a filter to detect and remove images unsuitable for analysis.
		Such a classifier must be capable of performing an analysis on a submitted image in a reasonable amount of time while satisfying classification with 66\% certainty.
		The algorithm must determine whether obstructions in the image will prevent proper Aerosol analysis, and reject unsuitable images accordingly.
	
	\subsection{Criteria}
		Third-party tools or libraries to be used in Aerolyzer's horizon classifier shall be compared by availability and utility.
		The Aerolyzer project shall ideally use non-proprietary software to perform image analysis.
		Such libraries are preferably open source with usage licenses compatible with \href{https://www.apache.org/licenses/LICENSE-2.0}{Apache License 2.0}.
		Additionally, such desirable libraries shall compliment the project with powerful image analysis tools such as proven algorithms or deep-learning frameworks.

	\subsection{OpenCV}
		OpenCV is a BSD-licensed computer-vision library with many relevant modules.
		Containing over 2,500 algorithms, OpenCV is capable of analyzing images and videos to recognize faces, identify objects, perform visual transformations, and much more.
		OpenCV's \textit{imgproc} module is an image processing component enabling image filtering, geometrical image transformations, and color space conversion. 
		Additionally, OpenCV's \textit{objdetect} module is able to detect predefined classes such as faces, eyes, and cars.
		These modules present useful frameworks that will be able to detect horizons given the proper tolerances and algorithms.
		OpenCV has promise to deliver a successful image-classifier filter due to its scalability and feature-rich library.

	\subsection{Google Tensorflow}
		Google Tensorflow is a supervised machine learning library created and distributed by Alphabet \textsuperscript{Inc.}.
		The library is broad and contains tools to accurately characterize a wide variety of potential weather conditions provided an adequate data set.
		This program has been proven to identify patterns in images with a high rate of consistency.
		Tensorflow requires a large set of training data to classify images.
		Generally, supervised machine learning libraries have a higher success rate than unsupervised libraries.

	\subsection{Amazon Rekognition}
		Amazon Rekognition is a supervised machine learning library that focuses on ease of use.
		Rekognition excels in object detection in images, but incurs a fee to process every 1,000 images.
		Amazon has built a large back-end library that is largely opaque to a user, the back-end classification algorithms are proprietary and cannot be directly modified.
		Rekognition performs analysis on Amazon’s AWS server, freeing up local resources for other processing.
		Rekognition is a less preferable venue due to its processing cost of \$1.00 per 1,000 images, and its closed-source development which restricts tuning the algorithm.

\section{Aerosol Content Inference}
	\subsection{Overview}

	\subsection{Criteria}
	After obstructions are distinguished, the Aerolyzer project shall analyze the extrapolated sky to infer Aerosol content.

	\subsection{OpenCV \& R \& Matlab Libraries}
	Incorporating R and Matlab libraries, OpenCV can be programmed to perform aerosol inference.
	However, a high level of atmospheric knowledge is required to create an accurate classifier.
	This can be accomplished by performing bitmap pattern matching against pre-selected atmospheric gradients with known aerosol content.

	Leveraging the statistical power of R and Matlab libraries will enable the Aerolyzer project to interpolate weather patterns from sampled images.
